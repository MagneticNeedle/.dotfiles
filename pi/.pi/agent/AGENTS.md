# Instrustions for the agents working on this repo

# General
1. In chat do not over explain
2. Be consise
3. Highlight things that maybe missed as they are not obvious
4. Use easy to understand language

# Coding
1. in code only add comments for things that are very non obvious to understand by reading the code
2. Follow Write everything twice, as soon as you see something being written for the third time, abstract or move it to a common place
3. For comment be very selective, only comment on things that once cant understand quickly without reading the code.

# Commiting
1. When commiting, only write commit message no discription for that commit
2. always try to work in a way that you can do atomic commits
3. always use conventional commit messages.

# Pull requests
1. In PR body dont over explain, keep the explanation to the point and short
